# Qualifier

Assess a bounded request for a declared use. The CLI uses the local schemas
from its `quaecer-spec-qualification` dependency and reads one request from standard input.

```sh
qualifier serve-process < request.json
qualifier assess --input request.json
```

For development, `--spec-dir` selects a trusted checkout's schema directory.
The assessment checks exact policy, registry and report bindings before
interpreting observations. The current operators handle executed checks,
decimal controls, dependence, run status, selection and artifact bodies.
The result distinguishes decisive values, contradictions, untested checks
and inapplicable criteria.

An accepted temporal premise leaves compatibility unresolved in this draft.
Coverage, absence and transfer remain deferred. A positive output states
conditional prerequisites and carries no authorization.
